# TRAVIA Website UI Direction

The public website represents a premium Dubai luxury travel brand.

## Character
- luxurious
- editorial
- cinematic
- modern
- confident
- elegant
- highly intentional

Luxury should come from typography, composition, imagery and restraint.

## Prefer
- exceptional typography
- strong photography
- deliberate whitespace
- editorial layouts
- refined motion
- sophisticated responsive behavior
- clear booking/contact conversion paths

## Avoid
- generic SaaS layouts
- repetitive card grids
- purple AI gradients
- decorative blobs
- excessive glassmorphism
- fake luxury through excessive gold
- giant generic hero copy
- arbitrary animations

For substantial UI work:
1. inspect the existing page/components
2. define the visual direction
3. implement
4. run the website
5. visually inspect it
6. verify desktop and mobile
7. fix typography, layout, spacing and interaction defects

Prefer relevant ECC frontend design skills when useful.
